FrameCraft 0.2.0 brings the editor much closer to MENiAC FRAME: its look, viewport tools, property controls and timeline, plus fonts and safer project handling. Projects from 0.1.0 and FRAME packs open as before.

## Install (Linux)

Download `framecraft_0.2.0_amd64.deb` below and install it:

```
sudo apt install ./framecraft_0.2.0_amd64.deb
```

Needs Ubuntu 22.04 or newer (or another distribution with WebKitGTK 4.1).

## What's new

### Look and layout
- FRAME's gray theme.
- The timeline sits under the viewport and the side column runs full height. Panels can be resized and keep their size.
- The status bar shows what the pointer is over, without a second tooltip on top.
- Tab switches between the Project view and the editor.

### Viewport
- Wheel zooms at the pointer; the middle mouse button pans.
- Guides: 10 % and 20 % safe areas, center cross, thirds, and custom rulers with draggable handles. Moving and resizing layers snap to them.
- Align buttons (left, center, right, top, middle, bottom) at the bottom left.
- Multi-select (Ctrl+click): move, align and make a component from several layers.
- FRAME's checkerboard behind the graphic, scaled with the zoom.

### Properties
- Number fields are FRAME's pills; drag a field's label to change the value (Shift ×10, Alt ×0.1).
- One color picker everywhere (active palette, stock palettes, RGBA sliders, hex), including gradient stops, chart colors and palettes.
- Gradient editor, gradient center pad for circle, ellipse and conic fills, and the particle lifetime curve editor.
- Border: animated width and FRAME's 4-sided mode.
- Resolution presets (video, web banners, social, ads).
- Info buttons next to section titles, as in FRAME.
- An animated field can drop its animation channel (✕ next to the keyframe diamond).
- Enter and Escape leave a field, so keyboard shortcuts work again.

### Timeline
- At 1× the whole duration fits; zoom up to 64× (slider, Ctrl+wheel at the pointer). Shift+wheel and the middle button pan, and playback follows the playhead.
- FRAME's time formats: ms, seconds, mm:ss, hh:mm:ss, frames and timecode. The playhead time can be typed.
- Drag the bar between two keys to slide the whole tween.

### Projects, fonts and palettes
- New asks where to create the project and saves it straight away, so autosave and crash recovery work from the start.
- New and Open now ask about unsaved changes too, as closing the window does.
- Import fonts (.ttf, .otf, .woff, .woff2) in Project → Fonts and pick them in text layers. Exports include the fonts that layers use; fonts in FRAME packs now work too.
- Palettes: deleting asks first, and new palettes start with FRAME's starter colors.

## Fixes
- Changing the pivot shows at once in the viewport.
- 4-sided borders are kept in the viewport and in exported graphics (FRAME's runtime overwrote them with one width).
- Built-in icons show before a project is open.
- Saving from the unsaved-changes prompts works.

## Note for exported graphics

The exported runtime differs from FRAME's in one place: the border width is written each frame only when it is animated, so 4-sided borders survive. Everything else in the export packages is unchanged.
