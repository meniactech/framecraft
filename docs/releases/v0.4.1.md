FrameCraft 0.4.1 is a small update: an app icon, pixel rulers, visible paths, and a few editor fixes.

## Download

| System | File | How to run |
|---|---|---|
| Linux (any distribution) | `FrameCraft-0.4.1-x86_64.AppImage` | `chmod +x` it and run; nothing to install |
| Ubuntu / Debian | `framecraft_0.4.1_amd64.deb` | `sudo apt install ./framecraft_0.4.1_amd64.deb` |
| Windows 10 / 11 | `FrameCraft-0.4.1-windows-x64.zip` | Unzip and run `FrameCraft.exe` |
| macOS 11 or newer | `FrameCraft-0.4.1-macos.zip` | Unzip, then right-click `FrameCraft.app` → Open the first time |

The Linux packages need Ubuntu 22.04 or newer (or another distribution with WebKitGTK 4.1). The Windows and macOS builds are still a preview: unsigned, and not yet widely tested.

## What's new
- **App icon**: FrameCraft has its own icon in the window, taskbar and app menus, and on the Windows `.exe` and the macOS app.
- **Pixel rulers** along the viewport's top and left edges, in scene pixels, following zoom and pan, with a mark at the pointer. Drag from one into the scene to add a custom ruler. Show or hide them with the **Px rulers** button, **View → Pixel rulers** or **Ctrl+R**.
- **File → Quit** (**Ctrl+Q**), asking to save unsaved changes first.
- **Editor | Project** tabs in the header. The Project view now sits under the menu bar, so the menus work there too.
- **Paths**: a path that is only a motion guide is drawn dashed in the editor (hidden while playing), as in FRAME. **Look → Points → Keep Visible** makes it a real stroke in playback and exports.

## Fixes
- Paths were invisible in the editor; only their points showed.
- The menu bar showed through the Project view, over the project name.
- A blurred plate let the viewport show through its edges; it is now scaled up slightly inside the scene, as in FRAME.
- The resolution label above the viewport is gone (the status bar shows it).
