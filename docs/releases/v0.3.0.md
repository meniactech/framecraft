FrameCraft 0.3.0 renders graphics to video, gets a proper menu bar, and comes as an AppImage plus first Windows and macOS builds.

## Download

| System | File | How to run |
|---|---|---|
| Linux (any distribution) | `FrameCraft-0.3.0-x86_64.AppImage` | `chmod +x` it and run; nothing to install |
| Ubuntu / Debian | `framecraft_0.3.0_amd64.deb` | `sudo apt install ./framecraft_0.3.0_amd64.deb` |
| Windows 10 / 11 | `FrameCraft-0.3.0-windows-x64.zip` | Unzip and run `FrameCraft.exe` |
| macOS 11 or newer | `FrameCraft-0.3.0-macos.zip` | Unzip, then right-click `FrameCraft.app` → Open the first time |

The Linux packages need Ubuntu 22.04 or newer (or another distribution with WebKitGTK 4.1).

**Windows and macOS builds are a first preview:** they build automatically but have not been tested on real machines yet, and they are not signed (Windows SmartScreen: "More info" → "Run anyway"). Feedback is welcome.

## What's new

### Render to video
- Properties → Export → **Video** renders the open graphic frame by frame at its size and frame rate: a **PNG sequence**, or with FFmpeg installed **ProRes 4444** (`.mov`) and **WebM VP9** — both with transparency — or **MP4 H.264**.
- On Linux each frame is captured by WebKit itself in a hidden view, so particles, charts, images and video are all in the render; Export → PNG Frame uses the same capture.
- Progress bar with Cancel. Pause cues are rendered straight through for now.

### Menu bar
- **File | Edit | Layer | View | Timeline | Help** replaces the row of buttons. Every item shows its shortcut; Undo / Redo name the step they undo.
- **Recent projects** in the File menu.
- New shortcuts: Ctrl+N (New), Ctrl+O (Open). Help → Keyboard shortcuts lists them all.

### Timeline
- Playback stops at **pause cues**, as in FRAME; Play again continues to the next one.

### Updates
- FrameCraft tells you in the status bar when a newer release is out (it checks GitHub at most once a day; nothing about you or your projects is sent). Turn it off in the Project view.

## Known limits
- On Windows and macOS, renders and PNG frames do not include canvas layers (particles, charts) or images yet; native capture there comes later.
- API and Script cues do not run during playback in the editor (exported graphics are unaffected).
