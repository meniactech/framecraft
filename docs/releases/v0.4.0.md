FrameCraft 0.4.0 imports Photoshop files, renders around pause cues the way MENiAC Air does, and makes the timeline easier to step through.

## Download

| System | File | How to run |
|---|---|---|
| Linux (any distribution) | `FrameCraft-0.4.0-x86_64.AppImage` | `chmod +x` it and run; nothing to install |
| Ubuntu / Debian | `framecraft_0.4.0_amd64.deb` | `sudo apt install ./framecraft_0.4.0_amd64.deb` |
| Windows 10 / 11 | `FrameCraft-0.4.0-windows-x64.zip` | Unzip and run `FrameCraft.exe` |
| macOS 11 or newer | `FrameCraft-0.4.0-macos.zip` | Unzip, then right-click `FrameCraft.app` → Open the first time |

The Linux packages need Ubuntu 22.04 or newer (or another distribution with WebKitGTK 4.1). The Windows and macOS builds are still a preview: unsigned, and not yet widely tested.

## What's new

### Photoshop (PSD) import
- **File → Import Photoshop file (PSD)…** (also in the Layer menu): every layer becomes a FrameCraft layer at its place, with its opacity, visibility and blend mode. Groups become Empties; everything goes under one Empty named after the file, as one undo step.
- **Text layers come in as editable text**: the text, font (matched to your project and built-in fonts), size, colour and alignment. The original Photoshop rendering is kept as a hidden layer underneath for comparing. Fonts you don't have yet are named in the status bar.
- 8-bit RGB documents. Not yet: large documents (PSB), 16/32-bit, CMYK, layer masks and effects, mixed styles within one text layer.

### Render to video
- **Pause cues, as MENiAC Air renders them**: a clip up to each pause plus a still at each pause and a `*_render.json` listing them in order (for holding in an editor); or each pause held for a set time in one file; or straight through.
- **macOS**: renders and PNG frames now capture natively, like on Linux, so particles, charts and images are included (new in this release; not yet tested on a real Mac).

### Timeline
- **‹ ›** next to every lane jumps to its previous / next keyframe and selects it; next to every cue row, to the previous / next cue.
- **API and Script cues fire during playback** in the editor, as in FRAME: the request is sent / the graphic's script function is called, with the result in the status bar.
